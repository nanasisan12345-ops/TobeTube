PRIVACY POLICY

プライバシーポリシー

TobeTubeは個人が趣味で運営する、国とジャンルから公開動画を発見するための無料Webサービスです。

最終更新日: 2026年9月4日

YouTube APIサービスの利用

TobeTubeはYouTube Data API v3およびYouTube IFrame Player APIを利用しています。YouTube Data APIは、公開動画の動画ID、タイトル、チャンネル名・チャンネルID、長さ、公開再生回数、公開状態、埋め込み可否などの公開情報を取得し、国・ジャンル別の動画候補を更新するために使用します。

閲覧者のブラウザーからYouTube Data APIを直接呼び出すことはなく、APIキーも閲覧者へ公開しません。動画はYouTube公式の埋め込みプレーヤーで再生し、動画ファイルのダウンロード、複製、再配布は行いません。

YouTubeとGoogleによる情報の取り扱いについては、GoogleプライバシーポリシーおよびYouTube利用規約をご確認ください。

ブラウザーに保存する情報

TobeTubeは、選択した国・ジャンル、表示テーマ、お気に入り、最近見た動画の動画IDを閲覧者のブラウザー内のローカルストレージへ保存します。これらはTobeTubeのサーバーへ送信されず、氏名、住所、Googleアカウント情報を収集するものではありません。

ブラウザーデータを削除する方法

保存情報は、ブラウザーのサイト設定からこのサイトの保存データを削除することでいつでも消去できます。Chromeでは、アドレスバー左側のサイト情報から「サイトの設定」を開き、「データを削除」を選択してください。GoogleアカウントとのOAuth連携は行っていないため、連携解除の操作はありません。

第三者提供・広告・Cookie

TobeTube運営者は、閲覧者の個人情報を販売せず、広告目的で第三者へ提供しません。TobeTube自体はログイン機能や独自のCookieを使用しません。埋め込みプレーヤーの利用時には、YouTubeまたはGoogleが各社のポリシーに基づいて情報を処理する場合があります。

お問い合わせ

本ポリシーに関する連絡は、TobeTubeのGitHub Issuesからお願いします。本ポリシーは、サービス内容や適用される規約の変更に応じて更新する場合があります。

English summary

TobeTube is a free, non-commercial hobby project that uses the YouTube Data API v3 and YouTube IFrame Player API to help users discover public, embeddable videos by country and genre. Public API data such as video IDs, titles, channel details, duration, public view counts, availability and embeddability is used to maintain the catalog. The API key is never exposed to visitors, and video files are not downloaded or re-hosted.

Country and genre selections, theme, favourites and recent video IDs are stored only in the visitor's browser. TobeTube does not use OAuth, collect Google account information, sell personal data or display advertising. Users can delete locally stored data at any time from their browser's site settings. See the Google Privacy Policy and YouTube Terms of Service.
